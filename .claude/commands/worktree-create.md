# Create Worktree

Create a new git worktree with a random name for isolated work.

## Instructions

1. Run the worktree creation script:

   ```bash
   ./scripts/worktree-create.sh
   ```

2. The script outputs the path to the new worktree. Use `cd` to change into that directory.

3. Confirm to the user that you are now working in the worktree and show them the worktree name/path.

4. Continue with any subsequent work from within the worktree directory.
