   - [ ] `film-stock-input` - film stock text field

## Status Values

- `### Status: In Progress` - actively being worked on
- `### Status: Complete` - all tasks finished and verified

## Conventions

- Use checkboxes `[ ]` for pending, `[x]` for done
- Group tasks by layer (data, tests, components, screens)
- Include testIDs from tester-maestro output for reference during coding
